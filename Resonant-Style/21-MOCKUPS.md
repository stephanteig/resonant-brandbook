# 21 — MOCKUPS

## Purpose

This inventory defines the visuals required to turn the design system into a real Brand Book rather than a text specification.

## Screen specification

Every screen must document purpose, audience, information hierarchy, components, interactions, responsive behaviour, accessibility, future improvements, status, and asset provenance.

## Visual ratio target

For the Canva Brand Book, target roughly 60–70% visual material and 30–40% explanatory text. Source documentation remains detailed; the PDF presentation should be selective, spacious, and image-led.

## Editorial mockup direction

The product surfaces should be shown at a scale where hierarchy and atmosphere are immediately legible. Use full-browser compositions for Home and Player, focused analytical cards for Taste, review states for Playlist Review, and three-level recommendation compositions for Discover. Pair one large product proof with one short rationale; move implementation detail to the reference pages.

```text
Principle → product proof → annotated decision → reference rules
```

Do not present every surface as the same dark rectangle. Vary the crop, scale, device frame, artwork density, and amount of surrounding negative space while preserving the same shell, type, colour, and logo system.

## Illustration Required

Each screen above requires a final page brief containing purpose, description, suggested composition, priority, and assets required. Use fixture data only until real user-authorized data is available. Each logo application requires the same provenance note and must preserve the approved geometry.
