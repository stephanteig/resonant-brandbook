# Editorial Visual Assets

These visual fixtures support the Version 0.4 presentation PDF. They are used to create atmosphere, album-art placeholders, and editorial pacing; they are not claims about shipped product functionality.

## Assets

- `resonant-hero-night-water-v0.4.png` — wide nocturnal listening photograph for hero and marketing spreads.
- `resonant-album-artwork-v0.4.png` — square abstract artwork fixture for product mockups and cards.

## Usage rules

Keep copy outside the artwork unless the layout explicitly calls for an editorial overlay. Do not attach the artwork to a real artist, album, or Spotify catalogue item. Replace fixtures with cleared photography or user-authorized artwork before external marketing publication.
