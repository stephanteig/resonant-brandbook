# Resonant Logo Assets

This folder contains the Version 1 Resonant identity used by the Brand Book and visual presentation builder.

## Source of truth

The editable source files live in `Source/`. `Resonant-Logo.af` is the Affinity source, while `Source/01-Primary-Full-Color.svg` is the primary vector export. The approved colour variants live in `Color-Variations/`:

- `01-Primary-Full-Color.svg`
- `02-Monochrome-Black.svg`
- `03-Monochrome-White.svg`
- `04-Monochrome-Forest.svg`
- `05-Monochrome-Emerald.svg`
- `06-Monochrome-Lime.svg`
- `07-Grayscale.svg`

The `Color-Variations/png/` folder contains the supplied PNG variants used by the PDF builder and raster applications. The `Exports/` folder contains earlier generated derivatives and is not the authoritative source. SVG remains the preferred format for product, web, and print delivery when vector support is available.

## Replacement workflow

When an approved source asset is delivered, update the editable source and replace the matching files in `Color-Variations/` and `Color-Variations/png/`. Do not alter document structure or redraw the mark in application code. Any replacement must preserve the approved geometry, cut-out, optical proportions, rounded terminals, and colour treatments.

## Usage

Use the primary gradient and Emerald variants on dark surfaces, white on dark surfaces, and black on light surfaces. Forest, Lime, and Grayscale are approved monochrome options for controlled applications; check contrast before use. Treat every export as artwork, not as a source for reinterpretation. Review small-size, print, sticker, apparel, and embroidery output separately before production.

## File placement

Keep editable masters in `Source/`, approved vector variants in `Color-Variations/`, supplied raster variants in `Color-Variations/png/`, and legacy generated derivatives in `Exports/`. Keep mockups in `../Mockups/`; keep construction and clear-space diagrams in `Guides/` when they are added. Do not place screenshots or merchandise photography in this folder.
