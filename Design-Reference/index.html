Resonant UI Kit

A quiet system for music, context, and decisions.

This is the visual foundation for Resonant’s website, desktop app, future mobile surfaces, marketing mockups, and product screenshots. It turns Brand Book v0.5 into named, reviewable interface decisions.

Design principle. Every element must earn its place. If removing it makes the page stronger, it should be removed. If adding it does not make the story clearer, it should not exist.

01 / SYSTEM

One source of truth.

The kit is organized around the Brand Book’s visual roles: display leads, interface clarifies, data aligns. Components preserve the listening thread instead of competing with it.

FOUNDATIONS

Tokens & principles

Colors, type, space, grid, elevation, motion, icons, and artwork.

COMPONENTS

Named interface parts

Controls, navigation, music, review, discovery, feedback, and states.

PATTERNS

Flows with context

Search, sync, playlist review, discovery, onboarding, and settings.

EXAMPLES

Composed surfaces

Reference screens assembled from the system, not one-off styling.

02 / AT A GLANCE

Quiet surfaces. Clear hierarchy. One useful signal.

The visual language is dark-first, editorial, restrained, and deliberately human. Accent is earned by the content it helps explain.

Color

Space is the default.

Canvas and surface carry most of the interface. Accent and mint signal meaning, not decoration.

Interaction

Control stays visible.

Focus, loading, error, and disabled states are part of the component contract.

Product

Music comes first.

AI, taste, and discovery add context without turning Resonant into a generic dashboard or chatbot.

03 / STATUS

Ready for the next surface.

Foundations and representative component states are documented in the linked reference pages. The kit is intentionally static and safe to inspect.
