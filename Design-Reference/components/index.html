Components

Named parts for a coherent product.

Every component below is a static reference contract. Use it when composing a surface; do not invent one-off variants that differ only by padding or color.

State rule. Every interactive component must account for default, hover, pressed, focused, disabled, loading, and error where applicable. Essential information must never depend on hover.

01 / CONTROLS

Actions should feel calm and explicit.

Buttons name the consequence. Inputs preserve context. Destructive and data-affecting actions never hide behind ambiguous iconography.
