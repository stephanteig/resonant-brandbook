Foundations

The quiet rules behind every surface.

These values are the shared grammar of Resonant. They are not decoration: they control emphasis, readability, confidence, and the way music remains the primary subject.

01 / COLOR

One useful signal.

Color should arrive as a signal. Space is the default. Never use color alone to communicate state, confidence, or connection.

03 / SPATIAL SYSTEM

Spacing is a rhythm.

Use an 8px mental grid while preserving rem-based implementation tokens. Larger gaps create editorial breathing room; smaller gaps group related information.

8 / MICRO
16 / CONTROL
24 / GROUP

64 / EDITORIAL

Desktop anatomy

15rem persistent sidebar, constrained main content, page header, primary surface, contextual detail, and global player.

Mobile anatomy

Wordmark and environment in the header, primary content, global player, and sticky four-item navigation.

04 / SURFACE

Depth without spectacle.

Radius, blur, opacity, shadow, and elevation should clarify grouping and state. They should never become the visual subject.

RADIUS

4 / 8 / 16

4px for controls, 8px for surfaces, 16px only for larger grouped panels.

ELEVATION

1 / 2

One quiet shadow for floating controls. One deeper shadow for dialogs and major overlays.

BLUR

Use sparingly

Blur belongs to persistent overlays and translucent player context, not every card.

05 / MOTION

Motion keeps the thread.

Use motion to preserve orientation, reveal cause and effect, and make state changes legible. Respect prefers-reduced-motion.

Reveal

Short, soft opacity and translate transitions when content enters a new context.

Continuity

Player state persists across navigation rather than restarting or disappearing.

Feedback

Loading, sync, approve, and reject states should explain what is happening without noise.

06 / ICONS & ARTWORK

Every mark has a job.

Use Lucide-style line icons with visible focus states. Artwork provides emotional energy; UI geometry provides comprehension.

Icon rules

Use icons for recognition, never as unexplained decoration. Keep stroke weight consistent. Pair unfamiliar icons with labels. Never use color as the only state cue.

Artwork rules

Use album artwork for music identity, night photography for atmosphere, and signal forms for pattern and context. Do not use generic visual filler.
